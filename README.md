# Demand Forecasting using Machine Learning

##  Project Description
This project focuses on predicting product demand using machine learning techniques based on historical sales data and various influencing factors.

##  Dataset Information
- Total Records: 76000  
- Total Features: 16  
- Key Features:
  - Date
  - Store ID
  - Product ID
  - Category
  - Region
  - Inventory Level
  - Units Sold
  - Units Ordered
  - Price
  - Discount
  - Weather Condition
  - Promotion

##  Models Used
- Decision Tree  
- Random Forest  
- Support Vector Machine (SVM)  
- K-Nearest Neighbors (KNN)  
- Naive Bayes  
- AdaBoost  

##  Results
Different models were applied and evaluated using accuracy and confusion matrix. Random Forest and Extra Trees showed the best performance.

## 🎯 Objective
To analyze sales data and build machine learning models for accurate demand prediction.
